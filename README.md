# chenchangzhu.github.io

Homepage of Chenchang Zhu, Mathematisches Institut, Georg-August-Universität Göttingen.
Live at https://chenchangzhu.github.io.

- `index.html` – the page (plain HTML and CSS, no build step)
- `hero-bg.svg`, `section-bg.svg` – chalkboard backgrounds, generated by `tools/board.js`
- `fonts/` – self-hosted Computer Modern (SIL Open Font License)
